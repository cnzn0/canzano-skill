# canzano

A house style and minimal design system for AI agents. This plugin carries one skill, `canzano`, which makes pages, reports, PDFs, decks, charts, diagrams and UIs come out precise instead of generic: Inter and Geist Mono, OKLCH colour, hairline structure, small crisp controls, and rules against fluff in text and UI copy.

## Install

```
/plugin marketplace add cnzn0/canzano-skill
/plugin install canzano@canzano
```

Once installed, ask as you normally would. The skill loads when you ask for a page, report, deck, chart, diagram or interface. Full documentation, examples and other install routes: https://github.com/cnzn0/canzano-skill
